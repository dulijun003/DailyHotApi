# 澄清需求：提问策略与题库

## 轮次规划

| 档位 | 第 1 轮 | 第 2 轮 | 第 3 轮 | 第 4 轮 |
|---|---|---|---|---|
| 快速 | 目的 + 读者 + 角度 + 篇幅风格（4 题合一） | — | — | — |
| 标准 | 目的、读者、角度（含档位） | 要点、边界、风格 | — | — |
| 深度 | 目的、读者、角度 | 核心问题与要点 | 边界、风格、形式 | 挑战性问题与查漏补缺 |

**动态调整**：用户的回答已经覆盖后面某轮的维度时，可以提前结束；回答引出了重大新问题时，可以多问一轮，但要告诉用户原因。

## AskUserQuestion 用法要点

- `header` 不超过 12 个字，比如"写作目的""目标读者""切入角度"。
- 每题 2–4 个选项；不需要提供"其他"选项，工具会自动加。
- 选项的 `label` 要短（1–5 个词），具体解释放在 `description` 里。
- 维度本身可以多选时（比如要点、要包含的模块），设 `multiSelect: true`。
- 有明显更好的选项时，放在第一位，并在 label 末尾加"（推荐）"，同时在 description 里说明理由。

没有这个工具时，使用下面的文字格式：

```
**问题 1｜写作目的**：这篇文章最主要想让读者获得什么？（可多选）
a) 看懂：系统理解 X 的来龙去脉
b) 判断：对"X 值不值得投入"形成明确观点
c) 上手：能按文章步骤实际做出 Y
d) 其他：请补充

👉 直接回复字母即可，例如 "1: a,b  2: c"，也可以附加说明。
```

## 题库（按维度，使用时必须结合主题改写成具体选项）

### ① 写作目的
- 读者读完后，你最希望他做什么？（理解原理 / 形成判断 / 付诸行动 / 改变看法 / 收藏备查）
- 这篇文章是独立的一篇，还是系列的一部分？
- 文章要为你带来什么？（专业影响力 / 涨粉 / 产品转化 / 内部决策依据 / 个人学习沉淀）

### ② 目标读者
- 读者是谁？（行业从业者 / 跨界的聪明外行 / 管理决策者 / 学生新手 / 投资人）
- 读者已经知道什么？哪些概念可以不解释，哪些必须解释？
- 读者在什么场景下阅读？（手机碎片时间 → 段落要短、要有小标题；电脑深度阅读 → 可以更密集）

### ③ 核心问题与要点
- 以下哪几个问题是这篇文章**必须回答**的？（根据主题列出 4 个候选问题，多选）
- 以下哪些模块需要包含？（数据与市场 / 典型案例 / 原理机制 / 实操步骤 / 争议与反方 / 未来预测 / 工具清单）
- 有没有你已知、而且一定要写进去的材料、观点或案例？

### ④ 立场与角度
- 你希望文章是：中立综述 / 明确观点（支持或反对）/ 反常识 / 对比评测 / 预测判断？
- **挑战式提问（每次澄清至少用 1 个）**：
  - "市面上大多数文章都在讲 A，但真正少有人讲的是 B（举例），要不要以 B 为主线？"
  - "你的假设可能是 X，但有证据表明 Y（简述）。文章要不要正面回应这个张力？"
  - "这个主题有一个常被忽略的利益相关方或维度 Z，要不要纳入？"

### ⑤ 范围边界
- 时间范围：只看最近一年 / 近 3–5 年 / 完整历史？
- 地域：中国 / 全球 / 中美对比？
- 明确不写什么？（列出 3–4 个容易跑题的相邻话题，让用户勾选排除）

### ⑥ 语言风格
- 学术严谨（术语准确，论证完整）
- 商业分析（数据驱动，结论先行，像咨询报告）
- 科普通俗（类比多，故事化，像优秀的科普作者）
- 教程实操（步骤清晰，可照做）
- 犀利评论（观点鲜明，有态度）
- 故事叙事（人物和事件驱动，像特稿）
- 可以追问："有没有你喜欢的作者或账号的文风可以参考？"

### ⑦ 形式规格
- 篇幅：2000 / 4000 / 6000 / 10000 字以上
- 语言：简体中文 / 繁体中文 / 英文 / 其他
- 发布平台：公众号 / 知乎 / 博客 / 内部文档 / Newsletter（这会影响排版和标题风格）
- 是否需要数据图表、配图方案、公众号排版版？
- 引用格式：文末参考资料（默认）/ 正文内链接 / 不需要

## 每轮结束时的复述模板

```
✅ 目前已确定：写给【读者】，目的是【目的】，以【角度】切入，篇幅约【N】字。
❓ 还需要确认：【下一轮要问的维度】
```
