# 自审清单（挑剔主编视角）

自审的立场：**假设这篇文章明天会被该领域最懂行、最不客气的读者逐字挑错。**

## A. 事实层（一票否决）

- [ ] 正文里每个具体数字、日期、人名、机构名、产品名，都能在 `02-notes.md` 找到对应的事实卡片
- [ ] 每个脚注编号都对应正确的来源，链接完整
- [ ] 没有"无来源的具体数据"（逐段扫描阿拉伯数字和百分号）
- [ ] 直接引语与原文一致
- [ ] 时效性数据标注了时间
- [ ] 单一来源的关键论断已经标注"据 X"或做了弱化处理
- [ ] 没有把预测、估计写成事实

## B. 逻辑层

- [ ] 核心判断明确，在开头或第一节就让读者知道
- [ ] 每节的论点都服务于核心判断
- [ ] 证据能真正支撑论点，而不是只有相关性
- [ ] 没有偷换概念，没有以偏概全（一个案例不等于普遍规律）
- [ ] 有反方观点和边界条件的讨论，并且做了回应
- [ ] 结论没有超出证据能支持的范围

## C. 价值层

- [ ] 至少 3 处"读者在别处不容易看到"的内容：独家整合、一手数据、反常识发现、清晰的框架
- [ ] 删掉标题后，读者仍能复述核心判断
- [ ] 目标读者读完后能获得简报里约定的收获
- [ ] 分析和观点占全文 40% 以上，不是资料堆砌

## D. 表达层

- [ ] 禁用表达清单（`05-writing-style.md` 第 3 节）全部清零。逐条搜索确认
- [ ] 开头 100 字有钩子，第一段不是背景介绍
- [ ] 没有重复论述（同一个意思在不同章节说了两遍）
- [ ] 段落长度适合目标平台；小标题本身能传递信息
- [ ] 专业术语第一次出现时有解释（视读者水平而定）
- [ ] 结尾有落点（判断、建议或开放问题），没有空洞升华
- [ ] 中文排版规范：空格、标点、大小写

## E. 规格层

- [ ] 篇幅在目标篇幅 ±10% 以内
- [ ] 语言、风格符合简报
- [ ] 简报里"必须覆盖的要点"全部覆盖，"排除内容"没有出现
- [ ] 配图标记位置合理（每 1500–2500 字一张）

## review.md 记录格式

```markdown
# 自审报告（第 1 轮）

| # | 层 | 问题 | 位置 | 修改 |
|---|---|---|---|---|
| 1 | 事实 | "增长 50%"无来源 | §2 第3段 | 补充来源 [S12]，修正为 47% |
| 2 | 表达 | 出现"值得注意的是"×3 | 多处 | 删除 |
| 3 | 逻辑 | §4 结论超出证据 | §4 末段 | 改为"至少在 X 场景下……" |

结论：通过 / 需第 2 轮修订
字数：5,980（目标 6,000）
```
