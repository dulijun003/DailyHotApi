# 配图方案

## 1. 配图数量和位置

- **封面图**：1 张，横版（公众号封面比例 2.35:1，通用横版用 16:9）
- **文中配图**：每 1500–2500 字一张，一般 2–4 张。放在以下位置：
  - 章节开头，用来营造氛围或引入概念
  - 抽象概念处，用示意图帮助理解
  - 关键数据处，用数据图表
- 在正文中用 HTML 注释标记位置：`<!-- 图2：AI Agent 与传统工作流的决策权对比示意 -->`

## 2. 三类图，三种做法

| 类型 | 用途 | 做法 |
|---|---|---|
| **数据图** | 趋势、对比、占比 | 能执行代码就用 Python matplotlib 画图，导出 PNG 到文章目录；不能执行就给出图表规格（类型、数据、标题、坐标轴） |
| **结构图/流程图** | 框架、流程、关系 | 用 Mermaid 代码（很多编辑器可以渲染），或者描述清楚让设计师绘制 |
| **概念插画/封面** | 氛围、隐喻 | 写生图提示词（Midjourney、GPT-Image、即梦、可灵、Gemini Image 等都可用） |

数据图的要求：标题要直接说出结论（例如"2023 年后增长明显放缓"，而不是"市场规模变化"）；注明数据来源；不用 3D 效果，不用饼图展示超过 5 个类别的数据。

## 3. 生图提示词规范

**整组图要使用统一的风格前缀**，保证视觉一致：

```
风格前缀（示例）：
扁平插画风格，柔和的低饱和配色（雾蓝、米白、珊瑚橙点缀），简洁几何构图，大量留白，无文字，16:9
Flat illustration, soft muted palette (misty blue, off-white, coral accents), clean geometric composition, generous negative space, no text, 16:9
```

可以选择的风格方向，按文章调性选：

- 科技分析：等距 3D、线框、深色背景加霓虹点缀
- 商业财经：极简扁平、编辑插画风格
- 人文社会：纸张质感、水彩、版画
- 科普教育：明亮扁平、卡通、信息图风格

**每张图的提示词结构**：风格前缀 + 主体 + 场景/隐喻 + 构图 + 光线/色调 + 排除项

- 用**视觉隐喻**表达抽象概念。例如"决策权转移"可以画成"一只机械手和一只人手在传递一枚棋子"。
- **不在画面里放文字**（生图模型容易写错字），需要文字的话后期再加。
- 避免出现真实人物肖像、品牌标志和受版权保护的角色。

## 4. images.md 格式

```markdown
# 配图方案：《文章标题》

风格前缀（中）：……
风格前缀（英）：……

## 封面图
- 位置：封面（2.35:1）
- 画面：……
- 隐喻：……
- 提示词（中）：{风格前缀}，……
- 提示词（英）：{style prefix}, ……

## 图1：……
- 位置：§2 开头（正文标记 <!-- 图1 -->）
- 类型：概念插画 / 数据图 / 流程图
- ……

## 数据图 D1：……
- 数据：（表格）
- 来源：[S5]
- 图表类型：折线图
- 已生成文件：chart-d1.png（如有）
```
