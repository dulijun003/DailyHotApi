# 联网研究与事实核查方法

## 1. 搜索策略

### 查询设计（每个子问题至少 3 种变体）
- **基础查询**：`主题 关键概念`
- **时效查询**：`主题 2026`、`主题 最新`、`topic latest 2026`
- **数据查询**：`主题 市场规模 报告`、`topic statistics report pdf`、`主题 白皮书`
- **一手来源查询**：`site:gov.cn 主题`、`site:arxiv.org topic`、`公司名 财报`、`产品名 official docs`
- **反面查询**：`主题 问题 批评`、`topic criticism`、`topic failure case`、`why X failed`
- **案例查询**：`主题 案例 复盘`、`topic case study`

### 中英文双语
英文资料在技术、学术和全球市场数据上通常更全，中文资料在国内政策、市场和本土案例上更全。**两种都要搜**，引用时注明原文语言，必要时附上原文关键句。

### 搜索 → 精读
- 搜索结果的摘要只能用来判断"这篇值不值得读"。
- 有价值的结果必须用 `WebFetch` 打开原文。用 prompt 指明要提取什么，比如"提取所有与 X 相关的数据、日期、出处和作者观点"。
- 长文档（报告、论文）分段读，重点看摘要、结论、数据表和方法论。
- 打不开的页面（付费墙、需要登录）：换一个来源，或者引用其他转述它的可靠来源，并注明"转引自"。

## 2. 来源分级

| 等级 | 类型 | 用法 |
|---|---|---|
| **A** | 政府统计、法规原文、学术论文、上市公司财报或公告、当事方官方声明、产品官方文档、权威机构原始报告 | 关键事实的首选来源 |
| **B** | 主流权威媒体的报道、知名研究或咨询机构的分析、行业协会、领域专家的署名文章 | 可以作为证据；关键数字最好追溯到 A 级来源 |
| **C** | 自媒体、论坛、百科、营销文章、AI 生成的内容农场 | **只能作为线索**，顺着它去找 A 或 B 级来源 |

警惕信号：没有作者或日期、数字没有出处、标题党、明显的利益相关方（厂商自己吹自己的产品）、各处互相转载但找不到源头。

## 3. 笔记格式（02-notes.md）

按子问题或视角分组，每条信息一张卡片：

```markdown
## 子问题 2：XX 的商业化进展如何？

[F07] OpenAI 2025 年营收约 XX 亿美元
- 来源：[S4] The Information, 2026-01-15 ｜ B
- 交叉验证：[S11] Reuters 报道一致 ✅
- 备注：非官方披露，正文需写"据报道"
- 用途：§3 商业化

[F08] ……
- ⚠️ 冲突：[S5] 称 30%，[S6] 称 45%，口径不同（前者为全球，后者仅美国）
- 处理：正文用 [S5]，注明口径

### 本子问题小结
- 结论：……
- 证据强度：强 / 中 / 弱
- 缺口：……
```

另外单独记录两类信息：

- **💡 洞见与意外发现**：和常识相反的信息、有意思的细节、能当文章钩子的事实。
- **🗣️ 可引用的原话**：保留原文和出处，翻译时附上原文。

## 4. 来源清单（03-sources.md）

```markdown
| 编号 | 标题 | 作者/机构 | 发布日期 | 等级 | URL |
|---|---|---|---|---|---|
| S1 | …… | …… | 2026-03-02 | A | https://… |
```

## 5. 核查纪律

1. **关键事实双源**：文章的核心论据、反常识结论和醒目数字，都需要两个独立来源。两家媒体转载同一篇通稿，只算一个来源。
2. **口径一致**：比较数字时，确认统计口径、时间、货币和单位一致。
3. **时间戳**：所有数据都写上"截至 X 年 X 月"或"X 年数据"。
4. **引语核对**：直接引语必须在原文里能找到。找不到就改写为间接引述，并标明出处。
5. **不确定就说出来**："据 X 报道""目前尚无官方数据""各方估计在 A–B 之间"，这样写比编一个精确数字更专业。
6. **不编造**：没有搜到就不写，或者如实写"未能找到可靠数据"。这一条没有例外。

## 6. 并行研究（深度档 + 有 Agent 工具时）

给每个子代理的任务说明要包括：

- 研究简报摘要（读者、目的、范围）
- 负责的视角和子问题清单
- 要求：优先 A 级来源，中英文都要搜，关键数字双源验证
- 返回格式：按上面的"事实卡片"格式，加上来源清单和本视角小结（结论、证据强度、缺口），不要写成文章

主代理负责汇总：去重、统一编号（重新编 F# 和 S#）、标出视角之间的矛盾。

## 7. 研究完成的判断

- [ ] 简报里的每个核心问题都有结论，或标明了"证据不足"
- [ ] 每个核心论点都至少有 1 条反面或质疑的证据被考虑过
- [ ] 关键数字都完成了双源验证或标注了单源
- [ ] 有至少 3 条"💡 洞见与意外发现"
- [ ] 来源中 A 级的占比合理（标准档建议 ≥ 30%）

没达标就补充搜索；补了两轮仍然缺，就如实告诉用户缺口在哪里。
