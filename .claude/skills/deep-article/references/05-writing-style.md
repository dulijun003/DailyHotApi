# 写作风格指南

## 1. 通用原则

1. **具体胜过抽象**：
   - ❌ "效率大幅提升"
   - ✅ "处理一张报销单的时间从 3 天缩短到 4 小时"
2. **判断胜过罗列**：每罗列一组信息之后，都要说明"所以呢？"
3. **一段一意**：每段只讲一件事，第一句就是这段的主旨。
4. **短句为主**：长句控制在 40 字以内，复杂的逻辑拆成几句来写。
5. **用读者的语言**：专业术语第一次出现时，用一句话或一个类比解释；目标读者是专业人士时可以不解释。
6. **有作者存在感**：在分析部分可以用"我""我们"，明确表达判断，并给出理由。
7. **把节奏写出来**：数据、案例、分析交替出现，避免连续三段都是数据或都是议论。

## 2. 六种风格的写法要点

| 风格 | 写法 | 典型句式 |
|---|---|---|
| **学术严谨** | 定义准确，限定条件写全，区分相关性和因果性，多引原始研究 | "在 X 条件下，研究发现……（N=…）" |
| **商业分析** | 结论先行，量化描述，使用框架（但不堆框架名词），落到决策 | "三个数字说明问题：……" |
| **科普通俗** | 类比和故事驱动，先讲现象再讲原理，制造"原来如此"的时刻 | "想象一下……" "这就像……" |
| **教程实操** | 步骤编号，每步说明"做什么、为什么、怎么验证"，配常见报错 | "第 3 步：……。如果看到……，说明……" |
| **犀利评论** | 观点鲜明，敢下判断，但论据扎实，批评对事不对人 | "说白了，……" "问题恰恰在于……" |
| **故事叙事** | 场景、细节、人物、冲突，以小见大，让数据为故事服务 | 具体的时间、地点、动作、对话 |

## 3. 禁用表达清单（去 AI 腔）

这些表达会让文章立刻显得像 AI 写的。**成稿和自审时必须清零。**

**开头和结尾套话**
- 在当今……的时代 / 随着……的快速发展 / 在……的浪潮下
- 总而言之 / 综上所述 / 总的来说 / 归根结底（放在结尾段开头时）
- 让我们一起…… / 未来已来 / 未来可期 / 值得期待
- 结尾空洞升华，比如"……必将迎来更加美好的明天"

**填充词和过渡词**
- 值得注意的是 / 需要指出的是 / 不可否认 / 毋庸置疑 / 显而易见
- 首先……其次……最后……（全文用超过一次时）
- 此外 / 另外 / 与此同时（连续段落反复开头）
- 某种程度上 / 在一定程度上（没有限定的具体含义时）

**空洞大词**
- 赋能 / 抓手 / 闭环 / 打通 / 底层逻辑 / 顶层设计 / 生态（滥用时）
- 革命性的 / 颠覆性的 / 前所未有的 / 里程碑式的（没有证据支撑时）
- 至关重要 / 不可或缺 / 举足轻重 / 深远影响
- 深入探讨 / 全面解析 / 一文读懂

**结构性 AI 痕迹**
- 每段都用"不仅……更……""既……又……"的排比结构
- 三连排比（"更快、更好、更强"），每段都有
- 每节结尾都总结一遍本节内容
- 小标题后紧跟"在本节中，我们将……"
- 过度加粗（每段都有好几处加粗），或者使用 emoji 作为装饰
- 每个观点都配"一方面……另一方面……"，最后不下判断

**修改方法**：删掉这类词，或者换成具体事实。删掉之后意思不变的话，说明它本来就是废话。

## 4. 引用与脚注

- 正文中的具体事实后面紧跟脚注：`2025 年市场规模约 120 亿美元[^3]。`
- 文末统一列出：

```markdown
## 参考资料

[^1]: 作者/机构.《标题》. 媒体/出处, 2026-03-02. https://…
[^2]: ……
```

- 同一来源多次引用，使用同一个编号。
- "据报道""据估计"这类转述要保留，不要把非官方信息写成定论。

## 5. 中文排版规范

- 中文和英文、中文和阿拉伯数字之间加一个半角空格：`使用 GPT 模型`，`共 3 个阶段`
- 数字和单位之间：`120 亿美元`、`35%`（百分号前不加空格）、`5 GB`
- 中文语境使用全角标点：，。！？：；「」或“”（全文统一）
- 英文专有名词保持官方的大小写：GitHub、OpenAI、iPhone、n8n
- 段落长度：手机阅读一段 2–5 行（大约 60–150 字）
- 小标题：每 600–1200 字设一个，标题本身就要传递信息，不要用"背景""分析"这类空标题
- 列表：并列信息超过 3 项时用列表，但不要把整篇文章写成列表

## 6. 篇幅控制

- 目标篇幅指正文字数，不含参考资料。允许误差 ±10%。
- 写超了：先删重复论述和没有信息量的过渡，**不要删证据**。
- 写少了：补充案例、反方讨论、数据解读，**不要注水**。
- 用 `wc -m` 或类似方法估算字数：中文按字符计算，英文按单词计算。
