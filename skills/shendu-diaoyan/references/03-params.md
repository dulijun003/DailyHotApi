## 根据平台展示第二组

### 篇幅（单选，没有默认值）

括号里的参考范围只是常见做法，供用户参考，不代表推荐。

| 平台 | 选项 | 参考 |
|---|---|---|
| 公众号 | 2000 / 3000 / 4000 / 5000 / 10000 / 20000 字 / 自定义 | 常见 3000–5000 字 |
| 知乎 | 2000 / 3000 / 4000 / 5000 / 10000 / 20000 字 / 自定义 | 回答常见 1000–3000 字，专栏文章 3000–8000 字 |
| 小红书 | 300 / 600 / 1000 字 / 自定义（上限 1000 字） | 正文常见 300–800 字，信息主要靠图片承载 |

**X 先选形态：**

```
**X 发布形态**（单选）
a) 单条推文：一个观点或金句（免费账号 280 字符，一个汉字算 2 个字符，约 140 个汉字）
```

- Thread：问条数，5 / 8 / 12 / 15 条 / 自定义。
- X 长文：问篇幅，1000 / 2000 / 3000 / 5000 字（英文按词数计）/ 自定义。

### 配图数量（单选；"只学习不发布"时跳过）
