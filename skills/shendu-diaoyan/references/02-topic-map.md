# 第 2 步：选题地图

选题地图有两个用途：一是给用户看的**学习地图**，展示这个领域的全景；二是**选题菜单**，用户从中挑一个作为本次研究的主题。

## 2.1 先问题量

```
**选题地图题量**（单选）
a) 20 题：每层 5 题，适合快速定方向
b) 40 题：每层 10 题，适合系统学习、建立全景
```

## 2.2 轻量联网校准（生成之前做）

用 2–4 次搜索了解这个领域**近 12 个月**的状况：

- 出现了哪些新概念、新范式、重要标准或协议？
- 哪些说法已经过时，或者已经被推翻？
- 主流实践有什么变化？

把发现记成 3–6 条简短要点，写在 `topic-map.md` 末尾的"时效校准"一节，并注明检索日期。这一步只是为了避免问题过时，**不要把搜到的产品名、版本号堆进问题里**。

## 2.3 生成：角色与方法

以下面的角色和方法生成问题：

> **角色：认知科学家、顶尖学习策略专家与跨领域"精通导师"（Mastery Mentor）**
>
> 你的方法论根植于**第一性原理**：穿透表层信息，直击领域的根本性真理。你运用**费曼学习法**的精神，用最简洁的语言解释复杂概念，以此检验和巩固理解。你相信，真正深刻的学习始于提出正确的问题，而不是记忆现成的答案。你的职责是针对学习者独特的【学习目的】和【当前层次】，量身打造一条由深度问题驱动的、从"知道"到"精通"再到"创造"的认知升级路径。

### 第零阶段：目标校准

先深度解读用户的【学习目的】和【当前层次】。这个组合是贯穿全程的"指挥棒"，决定知识探索的起点、广度、深度和侧重点。

- 小白、入门：问题从直觉和类比切入，避免术语堆砌。
- 资深应用者、领域权威：跳过常识，直接进入取舍、边界条件、反直觉现象和未解难题。
- 学习目的为"应用实践""问题解决"时，应用层和前沿层的问题比重向实操倾斜；为"概念理解""知识建构"时，基础层和连接层要更扎实。

### 第一阶段：解构与定义（是什么）→ 基础层

为领域划定一个精准的"边界框"，在边界内识别与学习目的最相关的核心概念，追溯它们背后的第一性原理。问题覆盖定义、关键概念和理论框架。

### 第二阶段：结构与分类（有什么）→ 连接层

梳理领域内与目标相关的主要分支、体系、流派，以及它们之间的关系；探究不同分类标准背后的逻辑，思考哪种分类对实现学习目的最有价值。问题引导学习者建立知识网络。

### 第三阶段：方法与实践（如何做）→ 应用层

针对与学习目的强相关的应用场景，把认知转化为行动步骤，提炼可复用的经验和最佳实践。问题要让学习者能据此动手。

### 第四阶段：实战与内化（怎么用）→ 前沿层

在复杂的真实场景中检验和精炼方法论：成功与失败案例的复盘、综合性项目挑战、个人行动准则的沉淀，以及该领域当前真正悬而未决的难题。

## 2.4 质量规则（必须遵守）

1. **每题都必须可研究、可回答**：能通过资料、实验或实践得到一个有依据的答案。禁止"终局是什么""是否会颠覆一切"这类无法验证的空泛预测。
2. **前提必须成立**：生成后逐题自检前提。前提错误的问题要改写，例如"函数调用的底层编译过程"（函数调用不存在编译）、引用来源不明的统计数字、把产品和开发框架当成同类比较。
3. **题目正文不写具体版本号和产品排名**：写成"应从哪些维度为 Agent 选择核心模型"，而不是"Claude X 和 GPT-Y 哪个好"。需要了解现状的问题标 🌐，到第 6 步联网核实。
4. **不凑数**：每层题量固定（5 或 10），但同一层内的问题不能换个说法重复问同一件事。
5. **具体胜过宏大**：避免"如何全面理解 X"这种问法，每题聚焦一个明确的知识点或决策点。

## 2.5 标签

- 🔴 **核心**：不掌握就无法理解这个领域。每层最多标 1/3。
- 🌐 **需核实时效**：答案会随时间变化，研究时必须联网核实。
- ⭐ **推荐选题**：适合写成一篇文章（有明确的读者价值、有讨论空间、材料可得）。全部问题中恰好标出 5 个，分布在不同层。

```markdown

> 层次：初级实操者　目的：应用实践　生成日期：2026-10-09

## 第一部分：基础层（是什么？——解构与定义）
1. 🔴 ……
2. ……
...

## 第二部分：连接层（有什么？——结构与分类）
11. 🌐 ……
...

## 第三部分：应用层（如何做？——方法与实践）
21. ⭐ ……
...

## 第四部分：前沿层（怎么用？——实战与内化）

...

## ⭐ 推荐选题（适合写成文章）

- ...（共 5 个）

## 时效校准（检索于 2026-10-09）
- ……
```

## 2.7 让用户选研究主题

展示选题地图后问：

```
**请选择本次研究主题**（任选一种方式）
a) 回复题号，例如"21"，或者组合几题，例如"21+26"
b) 选一个 ⭐ 推荐选题
c) 直接写你自己的研究主题
```

收到回复后，把选择整理成一句明确的**研究主题陈述**（研究什么、聚焦哪方面、不包括什么），请用户确认（"可以"或修改），然后写入 `state.md`，进入第 3 步。
