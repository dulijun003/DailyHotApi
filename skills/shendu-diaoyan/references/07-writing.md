# 第 7 步：写作与排版

文章和学习报告是两种东西：报告追求完整，文章追求**有取舍、有观点、有节奏**。大部分研究材料不会进入正文。

写作前先读：`requirements.md`、`report.md`、`sources.md`、`factcheck.md`，以及 `references/platforms.md` 里对应平台的规范。

## 7.1 标题与角度

给出 3 个方案。每个方案包含：

- **标题**：符合平台规范
- **角度**：一句话，说明这篇文章的核心论点和切入方式
- **开头钩子**：文章前两三句话怎么写，用来抓住读者

```
**选一个标题和角度**（单选）
a) 标题：……
   角度：……
   开头：……
b) ……（推荐）
c) ……
d) 其他（请直接写，或者让我混合某几个方案）
```

- 分步骤模式：等用户选择。
- 自动化模式：直接采用推荐方案，并在交付时说明为什么推荐它。

## 7.2 大纲

先写大纲，再写正文。大纲包括：

- 各节标题，以及每节的一句话要点
- 每节使用哪几条关键论断（写论断编号）
- 配图位置和用途，总数等于用户选的配图数量（含封面）
- 各节的字数分配，合计等于目标篇幅

分步骤和自动化模式下，大纲都不需要单独确认。

## 7.3 写正文

一次写完全文，不要分段拼接。

**写作要求：**

1. **只写有依据的内容**：事实、数据、引文必须来自 `report.md`，并且在 `factcheck.md` 里没有被判为 ❌。
2. **标注出处**：按平台规范处理。长文平台在文末列参考资料；小红书和 X 不放参考列表，但写进正文的数据要能说出出处。
3. **风格**：严格按需求确认单里选定的风格写。
4. **篇幅**：控制在目标的 ±10% 以内。如果研究材料撑不起目标篇幅，**不要注水**，按材料写，并在交付时告诉用户："材料足够写 X 字，比目标少 Y 字，原因是……"
5. **配图占位**：在要放图的位置写 `[配图N｜用途：……｜类型：封面/生成/图示/真实]`。类型的判断规则见第 8 步。

## 7.4 自我编辑（交付前必须做一遍）

逐项检查并修改：

- [ ] **删 AI 腔**：
  - 不用"在当今快速发展的时代""值得注意的是""综上所述""总而言之""赋能""底层逻辑""闭环""让我们一起来看看"这类套话。
  - 不用"不是……而是……"的句式反复制造转折。
  - 不在每段结尾都加一句总结或升华。
- [ ] **删空话**：每一段都要有一个具体的信息、例子或判断。删掉之后不影响理解的段落，直接删掉。
- [ ] **开头**：前三句话就要让读者知道"这篇文章和我有什么关系"。
- [ ] **事实**：再对照一遍关键论断，数字、人名、日期、引文都要和来源一致。
- [ ] **平台规范**：长度、标题字数、格式都符合 `platforms.md` 的要求。
- [ ] **受众**：通篇用目标受众能听懂的话写，术语第一次出现时要解释。

## 7.5 产出

写入 `article.md`，文件开头加上元信息：

```markdown
---
平台：公众号
标题：……
备选标题：……、……
摘要：……（公众号摘要 ≤ 120 字）
标签：……（小红书、知乎、X 需要）
字数：……
---
正文……
```

完成后进入第 8 步；配图数量为 0 时，跳到第 9 步。
