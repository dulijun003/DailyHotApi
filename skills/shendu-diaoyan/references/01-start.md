# 第 1 步：启动研究

## 要做的事

1. 确认今天的日期。
2. 新建研究目录 `research/<YYYY-MM-DD>-<主题英文短名>/`，创建 `state.md`。
3. 一次展示下面四项，等用户回复。

如果用户的第一句话已经包含某些项（比如"我是小白，想研究 AI Agent"），把这些项预先填好，只问剩下的项。

## 展示给用户的内容

```
开始深度调研。请依次回答下面 4 项（可以一次回复，例如"AI Agent / c / c / 分步骤"）：

**1. 研究领域关键词**（直接写）
例如：AI Agent、短视频运营、量化投资、认知心理学

**2. 当前层次**（单选）
a) 小白（完全陌生）
b) 入门（有理论储备）
c) 初级实操者（有限经验）
d) 资深应用者（丰富经验）
e) 领域权威（专家级）

**3. 学习目的**（单选）
a) 概念理解　　b) 问题解决　　c) 应用实践　　d) 技能掌握
e) 职业发展　　f) 知识建构　　g) 教学与分享　h) 创新与研究

**4. 研究模式**（单选）
a) 分步骤：研究简报、文章标题、终稿这三处都会停下来让你确认
b) 自动化：前面的选择做完后一路跑到底，最后一次交付
```

## 处理回复

- 把四项写进 `state.md`，当前步骤更新为 2。
- 关键词太宽泛也没关系（例如"AI"），第 2 步的选题地图会帮用户收窄。
- 关键词有歧义时（例如"Agent"可能指 AI Agent，也可能指代理商），先用一句话确认再继续。
