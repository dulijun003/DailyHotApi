# 需求确认单
- **研究主题**：AI Agent 的间接提示词注入：攻击如何发生，架构层面哪些防御真正有效
- **研究目的**：学完后能做到三件事：① 讲清楚间接注入的原理和完整攻击链；② 审视自己做的或在用的 Agent，找出注入风险点；③ 为 Agent 设计分层防御架构，并说清每一层防什么
- **目标受众**：用户本人（初级实操者，有有限的 Agent 实践经验）
- **核心要点**：
  1. 原理层：为什么模型难以可靠区分"指令"和"数据"
  2. 攻击面全景：网页、邮件、文档、工具返回、MCP 工具描述、记忆库与知识库等入口
  3. 真实案例拆解：公开披露的漏洞与事件，按攻击链复盘
  4. 防御手段逐个评估：能防什么、防不住什么、代价
  5. 参考架构：分层防御蓝图，标出权限、隔离、人工确认的位置（AI 建议：在本节末尾附一个"按此架构排查自己 Agent"的简要步骤，服务于目的 ②）
- **语言风格**：技术拆解（图解 + 伪代码，拆到能实现的程度）
- **主题边界**（AI 建议）：
  - 覆盖：间接注入（不可信的外部内容进入 Agent 上下文）；与之紧密相关的数据外泄、越权调用工具；工具和 MCP 生态中的投毒
  - 不包括：用户本人越狱；模型训练层面的对齐细节；传统 Web 安全（只作类比）；某个具体防护产品的评测
  - 时效：攻击手法和防御研究优先采用近 12 个月的资料；原理性内容不限年份
- **平台 / 形态**：只学习不发布（产出学习报告）
- **篇幅**：10000 字
- **配图**：无（报告中的架构图和流程图用 Mermaid 代码表示）
- **语言**：简体中文

标注"（AI 建议）"的项没有在访谈中问到，是根据已有信息给出的建议。
