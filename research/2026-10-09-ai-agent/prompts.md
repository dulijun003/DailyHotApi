# 研究提示词（1 个核心 + 5 个聚焦）
可以复制到其他深度研究工具中使用。

## 核心综合提示词：关于"AI Agent 间接提示词注入"的深度研究
- 研究主题：AI Agent 的间接提示词注入：攻击如何发生，架构层面哪些防御真正有效。
- 研究目的：让读者能讲清原理与完整攻击链，能排查自己 Agent 的注入风险点，并能设计分层防御架构、说清每层防什么。
- 目标受众：有一定 Agent 实践经验的初级实操者。
- 关键点与框架：① 为什么模型难以区分指令和数据；② 攻击面全景（网页、邮件、文档、工具返回、MCP 工具描述、记忆库与知识库）；③ 4–6 个公开披露案例的攻击链复盘；④ 各类防御（检测、提示技巧、架构隔离、权限与执行层控制）能防什么、防不住什么、代价；⑤ 分层防御参考架构，以及排查自己 Agent 的步骤。
- 要求：优先使用论文、厂商安全公告、研究者原文；近 12 个月资料优先；每个关键论断附出处与日期；事实与观点分开；不讨论用户越狱和模型训练细节。
- 风格：技术拆解，配图解（Mermaid）与伪代码。
- 篇幅：约 10000 字。语言：简体中文。

## 聚焦提示词 1：原理机制
在核心提示词的基础上，聚焦"为什么指令和数据分不开"：与 SQL 注入对比，说明不存在参数化查询等价物的原因；造成危害需要同时满足的条件，以及去掉任一条件的效果；模型层缓解手段的实测效果和局限；自适应攻击者面前检测类防御的表现。要求引用论文与评测数据。

## 聚焦提示词 2：攻击面与手法
聚焦攻击面全景：列出所有不可信内容进入 Agent 的入口，以及典型手法（隐藏文本、Markdown 图片外泄、工具描述投毒、工具定义篡改、记忆投毒、跨 Agent 传播），按攻击目标分类，并对比浏览器、编程、办公、客服四类 Agent 的主要暴露面。

## 聚焦提示词 3：真实案例
聚焦 4–6 个有一手资料的公开披露案例，覆盖不同入口和 Agent 类型。每个案例写清：恶意内容放置位置 → 如何被读取 → 触发什么动作 → 造成什么后果；根因分类；厂商修复方式与层级；修复后是否仍有绕过。只采用研究者原文和厂商公告。

## 聚焦提示词 4：防御评估
逐类评估防御：检测与过滤、提示层技巧、架构隔离（双模型模式、可信控制流与不可信数据分离、学术界的安全设计模式）、权限与执行层（最小权限、出口白名单、禁止自动渲染外链、人工确认、沙箱）。每类给出原理、能防什么、防不住什么、代价和证据，并说明公开基准的局限。

## 聚焦提示词 5：参考架构与落地
综合 OWASP、NIST 和主要厂商的官方指南，给出一个分层防御参考架构（用 Mermaid 绘制），标出信任边界、权限控制、隔离和人工确认的位置；讨论安全与可用性的权衡；比较三类 Agent 的配置差异；给出初级实操者排查自己 Agent 的分步方法。
